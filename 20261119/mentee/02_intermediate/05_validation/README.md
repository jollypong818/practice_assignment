# 실습 05 · Coverage·중복·누락 검사

**난이도:** 02_intermediate · **용도:** 수강생 TODO

## 목표
문자 위치의 합집합으로 Coverage를 계산하고 중복 ID를 따로 확인합니다.

## 먼저 알아야 할 용어
- **Coverage**: 중복 위치를 한 번만 세는 포함 비율
- **Gap**: 청크가 덮지 않은 문자 위치
- **Duplicate ID**: 같은 chunk_id가 중복 생성된 오류

|---|---|

| `D24-05-I02` | 합집합으로 덮은 문자 수와 Coverage를 계산합니다. |
| `D24-05-I03` | 빠진 위치의 연속 구간 및 중복 Chunk ID를 구합니다. |
| `D24-05-I04` | 통과·오류·반복량·Coverage를 구분한 보고서를 작성합니다. |

## 실행 방법
- 수정 대상: `tasks.py`. `main.py`는 실행 진입점입니다.
- VS Code의 **Git Bash**에서 이 폴더로 이동하여 실행합니다. 기존 Python 가상환경을 사용합니다.
- `python main.py`

## 완료 기준
3개 시나리오 Coverage 100%, 90%, 100%. Duplicate는 Coverage로만 검출 불가.

## 독립 실습과 결과
- 앞 교시가 미완성이어도 현재 폴더의 준비 코드와 `coursekit/` Checkpoint로 시작할 수 있습니다.
- 출력 파일은 해당 폴더의 `outputs/`에 생성됩니다. `data/raw/` 원문은 수정하지 않습니다.
- `expected/EXPECTED.md`는 평가 기준이지 실제 실행 로그가 아닙니다.
- 수강생은 실행 결과 외에 “어느 원문·어느 처리 버전·어느 실패 지점인가?”를 설명해야 합니다.
