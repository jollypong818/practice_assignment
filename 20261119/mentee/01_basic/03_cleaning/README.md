# 실습 03 · Text Cleaning · 공백과 줄바꿈

**난이도:** 01_basic · **용도:** 수강생 TODO

## 목표
숫자와 조건은 유지하면서 줄바꿈과 일반 본문 공백을 정리합니다.

## 먼저 알아야 할 용어
- **CRLF·CR·LF**: 서로 다른 줄바꿈 표현
- **Cleaning**: 의미 보존을 전제로 한 형식 정리
- **Idempotence**: 같은 처리 반복 시 결과가 유지되는 성질

## 구현할 TODO

| ID | 요구사항 |
|---|---|
| `D24-03-B01` | CRLF·CR 줄바꿈을 LF로 바꿉니다. 문단의 줄을 하나로 합치지 않습니다. |
| `D24-03-B02` | 연속된 공백·탭을 한 칸으로 줄이고 좌우 공백을 제거합니다. 빈 줄은 보존합니다. |

## 실행 방법
- 수정 대상: `main.py`. `main.py`는 실행 진입점입니다.
- VS Code의 **Git Bash**에서 이 폴더로 이동하여 실행합니다. 기존 Python 가상환경을 사용합니다.
- `python main.py`

## 완료 기준
문단 사이 빈 줄, 10분·초과·예외 유지. 오류 규칙으로 숫자를 삭제하지 않음.
