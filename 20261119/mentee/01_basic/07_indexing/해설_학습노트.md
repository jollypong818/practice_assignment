# 실습 07 · Indexing 상세 해설

**수준:** 01_basic · **구분:** mentee

이 문서는 개념과 구현의 이유를 설명합니다. Python 파일과 함께 읽되 다른 강의자료에 의존하지 않아도 됩니다.

## 처리 흐름

검증된 Chunk → E5 Embedding → Stage → Transaction Publish → Top-k 검색

## 핵심 개념과 구현 시점

### 구현 단계 1
Indexing 입력은 검증된 Chunk의 내용과 출처입니다. 임의로 만든 384개 숫자를 E5 Embedding이라 부르지 않습니다.

### 구현 단계 2
E5 모델은 한 번 로드해서 CPU로 추론합니다. passage와 query의 접두어, 모델 ID, 정규화, 차원을 동일 계약으로 유지합니다.

## 수강생이 자주 혼동하는 부분
- 단순 프로그램 실행 성공과 실제 DB·모델 실행을 구분합니다.
- 빈 결과/실패 사유를 임의로 정상 데이터로 바꾸지 않습니다.
- 코드 변경 전후에 같은 테스트와 원문 비교를 실행합니다.
