# 실습 01 · Document Collection · Raw File

**난이도:** 01_basic · **용도:** 수강생 TODO

## 목표
TXT 원문 바이트를 읽고 문서 ID·바이트 크기·SHA-256을 기록합니다.

## 먼저 알아야 할 용어
- **Raw File**: 가공하기 전 원본 파일
- **Byte**: 파일 크기 계산의 단위
- **SHA-256**: 바이트를 식별하는 해시값

## 구현할 TODO

| ID | 요구사항 |
|---|---|
| `D24-01-B01` | 입력 경로의 파일을 bytes로 읽어 반환합니다. 없는 파일은 명확히 실패해야 합니다. |
| `D24-01-B02` | 문서 ID·원문 파일명·바이트 수·SHA-256을 한 딕셔너리에 묶습니다. |

## 실행 방법
- 수정 대상: `main.py`. `main.py`는 실행 진입점입니다.
- VS Code의 **Git Bash**에서 이 폴더로 이동하여 실행합니다. 기존 Python 가상환경을 사용합니다.
- `python main.py`

## 완료 기준
DOC-ASSIGN 한 행, size_bytes>0, raw_sha256=64자리. 원본 수정 없음.

## 독립 실습과 결과
- 앞 교시가 미완성이어도 현재 폴더의 준비 코드와 `coursekit/` Checkpoint로 시작할 수 있습니다.
