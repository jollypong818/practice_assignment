# 실습 06 · Metadata 상세 해설

**수준:** 01_basic · **구분:** mentee

이 문서는 개념과 구현의 이유를 설명합니다. Python 파일과 함께 읽되 다른 강의자료에 의존하지 않아도 됩니다.

## 처리 흐름

Chunk+문서 정보 → Metadata Contract → 공개 버전·권한·분류 → Citation Mapping

## 핵심 개념과 구현 시점

### 구현 단계 1
Metadata는 본문이 아닌 관리 정보입니다. 문서 ID·원문 판·처리 판·위치를 함께 가져야 검색 결과의 근거를 설명할 수 있습니다.

### 구현 단계 2
문자 Span과 PDF page_number는 서로 다른 위치 단위입니다. TXT/Markdown에 존재하지 않는 페이지 번호를 만들어 넣지 않습니다.

## 수강생이 자주 혼동하는 부분
- 단순 프로그램 실행 성공과 실제 DB·모델 실행을 구분합니다.
- 빈 결과/실패 사유를 임의로 정상 데이터로 바꾸지 않습니다.
- 코드 변경 전후에 같은 테스트와 원문 비교를 실행합니다.

3. 반환된 ID와 위치로 실제 원문을 다시 찾을 수 있는가?
