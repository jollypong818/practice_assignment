# 실습용 가상 자료

- **가상 교육센터**의 문서입니다. 실제 기관의 규정이 아닙니다.
- DOC-ATTEND: Markdown 출석 안내, DOC-ASSIGN: TXT 과제 안내, DOC-FACILITY: HTML 본문·표, DOC-CAREER: 추출 가능한 한글 2페이지 PDF, DOC-SCAN: 텍스트층이 없는 이미지 PDF.
- DOC-UNSUPPORTED는 허용하지 않는 확장자를 분리하는 테스트 데이터입니다.
- 원본 `data/raw/`는 수정하지 않습니다. 개정 원문은 `data/versions/attendance_v2.md`에 있습니다.
- 첫 수집 예제에서는 문서 6건을 기록합니다. **5건의 지원 형식 + 1건의 지원하지 않는 형식**이고, 5건 중 스캔 PDF는 `needs_ocr`로 분리합니다. 따라서 **텍스트 파싱을 완료할 수 있는 문서는 4건**입니다.
- 이미지 PDF의 텍스트가 추출되지 않는다고 해서 일반적인 모든 빈 PDF가 스캔 문서라는 뜻은 아닙니다. 본 샘플은 원본이 이미지로 만들어진 것을 알고 있습니다.
- 파일의 한글·부정어·날짜·조건을 정제에서 제거하지 마세요.
