# 실습 03 · Cleaning 상세 해설

**수준:** 01_basic · **구분:** mentor

이 문서는 개념과 구현의 이유를 설명합니다. Python 파일과 함께 읽되 다른 강의자료에 의존하지 않아도 됩니다.

## 처리 흐름

raw_text → 일반 본문 전용 Cleaning → 정제 전후 검증 → clean_hash

## 핵심 개념과 구현 시점

### 구현 단계 1
NFC는 Unicode 정준 정규화이며, NFKC는 ① 등의 호환 문자까지 바꿀 수 있습니다. 손실 범위가 더 큰 NFKC를 무조건 적용하지 않습니다.

### 구현 단계 2
일반 prose의 연속된 가로 공백만 축약하고 줄바꿈 경계는 유지합니다. 코드 들여쓰기와 표의 탭 구분에는 같은 규칙을 적용하지 않습니다.

## 수강생이 자주 혼동하는 부분
- 단순 프로그램 실행 성공과 실제 DB·모델 실행을 구분합니다.
- 빈 결과/실패 사유를 임의로 정상 데이터로 바꾸지 않습니다.
- 코드 변경 전후에 같은 테스트와 원문 비교를 실행합니다.
