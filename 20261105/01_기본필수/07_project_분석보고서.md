# 도형 이미지 분류 전이학습 프로젝트 결과 보고서

분석 대상: `07_project.py`  
작성일: 2026-11-05  
분석 근거: 최종 실행의 터미널 출력과 같은 폴더의 `metrics.json`, `history.csv`, `predictions.csv`, `confusion.csv`

## 1. 프로젝트 흐름 요약

이 프로젝트의 목적은 사전학습된 소형 CNN의 특징 추출부를 활용하여 원(circle), 사각형(square), 삼각형(triangle) 이미지를 분류하는 것이다. 별도의 합성 이미지로 학습된 Backbone을 고정하고, 현재 데이터에 맞게 마지막 분류기(Head)만 학습하는 전이학습 방식을 사용한다. 사용 모델은 TinyShapeCNN 계열이며, 사전학습 가중치의 출처는 `synthetic_source_pretraining`이다.

먼저 `ImageFolder`로 학습 데이터와 검증 데이터를 읽는다. 클래스 번호는 `circle=0`, `square=1`, `triangle=2`이며, 데이터 구성은 다음과 같다.

| 데이터 구분 | 원 | 사각형 | 삼각형 | 합계 |
|---|---:|---:|---:|---:|
| 학습(train) | 12장 | 6장 | 3장 | 21장 |
| 검증(valid) | 3장 | 3장 | 3장 | 9장 |

입력 이미지는 32×32 크기로 조정한 뒤 RGB 3채널의 0~1 범위 텐서로 변환한다. 모델은 합성곱 층으로 이미지 특징을 추출하고, 이를 256개 특징으로 펼친 뒤 `Linear(256, 3)`에서 세 클래스의 점수(logit)를 출력한다.

`data/source_backbone.npz`에서 사전학습 가중치를 불러온 후 Backbone의 파라미터를 고정한다. 학습 대상은 마지막 Head의 가중치와 편향 771개다. `model.eval()`로 BatchNorm의 저장 통계를 유지하면서, Head에 대해서는 기울기를 계산하고 가중치를 갱신한다.

학습은 난수 시드 14, AdamW, 학습률 0.01, weight decay 0.0, 교차엔트로피 손실을 사용해 총 8 epoch 동안 진행한다. 매 epoch마다 역전파와 가중치 갱신을 수행하고 검증 손실을 측정한다. 이후 검증 손실이 가장 작은 시점의 모델 상태를 복원한다.

최종 예측은 각 이미지의 logit 중 가장 큰 값의 클래스 번호를 `argmax(dim=1)`로 선택한다. 정확도, Macro F1, 예측 목록, 혼동행렬, 학습 이력을 CSV와 JSON으로 저장한다. 오답이 있을 때는 해당 이미지를 저장하며, Grad-CAM으로 선택한 클래스 점수와 관련된 영역을 확인하도록 구성되어 있다. 이번 실행에서는 test 데이터를 사용하지 않았다.

## 2. 최종 실행 결과와 해석

최종 터미널 출력은 다음과 같다.

```text
{"accuracy": 1.0, "best_epoch": 8, "macro_f1": 1.0, "source": "synthetic_source_pretraining", "test_used": false, "valid_n": 9}
오답 수: 0 예측 행: 9 test 사용: False
```

| 항목 | 최종 결과 | 의미 |
|---|---:|---|
| Accuracy | 1.0 (100%) | 검증 이미지 9장 중 9장을 올바르게 분류함 |
| Macro F1 | 1.0 | 세 클래스의 F1이 모두 1.0임 |
| best_epoch | 8 | 실행한 8 epoch 중 8번째의 검증 손실이 가장 낮았음 |
| valid_n / 예측 행 | 9 | 검증 이미지 9장에 대해 예측 결과 9개를 생성함 |
| 오답 수 | 0 | 이번 검증 집합에서 잘못 분류한 이미지가 없음 |
| source | synthetic_source_pretraining | 별도 합성 이미지로 사전학습한 가중치를 사용함 |
| test_used | false | 결과는 검증 집합의 성능이며 test 성능은 측정하지 않음 |

[confusion.csv](confusion.csv)의 혼동행렬은 다음과 같다. 행은 실제 클래스, 열은 예측 클래스다.

| 실제 클래스 \ 예측 클래스 | circle | square | triangle |
|---|---:|---:|---:|
| circle | 3 | 0 | 0 |
| square | 0 | 3 | 0 |
| triangle | 0 | 0 | 3 |

원·사각형·삼각형을 각각 3장씩 모두 맞혔다. 다른 클래스와 혼동한 사례가 없어 클래스별 정밀도, 재현율, F1이 모두 1.0이며, 이들의 평균인 Macro F1도 1.0이다. 정확도와 Macro F1이 함께 높다는 점에서 이번 검증 집합에서는 한 클래스에만 치우쳐 정답을 맞힌 현상은 관찰되지 않았다.

[history.csv](history.csv)의 검증 손실은 다음과 같이 감소했다.

| epoch | 검증 손실 |
|---|---:|
| 1 | 0.820726 |
| 2 | 0.639278 |
| 3 | 0.431073 |
| 4 | 0.268643 |
| 5 | 0.174825 |
| 6 | 0.131810 |
| 7 | 0.106717 |
| 8 | 0.090493 |

검증 손실이 0.820726에서 0.090493으로 지속적으로 낮아졌으므로, 관찰한 학습 구간에서는 검증 데이터의 정답 클래스에 부여하는 확률이 전반적으로 개선되었다고 해석할 수 있다. 이 중 손실이 가장 낮은 8 epoch가 최종 모델로 선택되었다. 다만 이 결과만으로 8 epoch 이후에도 성능이 개선되는지, 또는 8 epoch가 다른 조건에서도 최적인지는 알 수 없다.

[predictions.csv](predictions.csv)에서 예측 클래스의 softmax 값은 약 0.7631~0.9863이다. 가장 낮은 값은 `square_002.png`의 0.7631이며, 이 이미지도 사각형으로 정확히 분류했다. 따라서 모든 예측이 정답이더라도 이미지별 분류 점수에는 차이가 있음을 알 수 있다. softmax 값은 모델의 출력 점수이므로 실제 정답 확률과 정확히 일치한다고 단정하지 않는다.

이번 실행의 오답은 0건이므로 별도의 오답 사례 분석 대상은 없다. 코드에서는 이 경우 첫 번째 검증 이미지인 `circle_000.png`를 Grad-CAM 대상으로 선택한다. 다만 본 보고서는 실제 CAM 이미지를 시각적으로 분석하지 않았으므로 모델이 도형의 특정 부위나 배경에 주목했다는 주장은 포함하지 않는다.

**이번 결과는 사전학습된 Backbone과 학습한 Head의 조합이 제공된 검증 이미지 9장을 모두 정확히 분류했음을 보여준다. 평가 범위는 해당 검증 집합이며, 새로운 이미지 전체에 대한 성능을 보장하는 결과는 아니다.**

## 3. 한계점과 보완 방안

| 한계점 | 현재 결과에서 판단할 수 있는 범위 | 보완 방안 |
|---|---|---|
| 검증 데이터가 9장으로 적음 | 한 장의 정오 여부만 달라져도 정확도가 약 11.11%p 변함. 100%라는 수치만으로 성능의 안정성을 판단하기 어려움 | 클래스별 검증 데이터를 늘리고, 서로 다른 분할과 여러 난수 시드에서 평균 성능과 변동을 확인 |
| 학습 데이터가 12:6:3으로 불균형함 | 이번에는 모두 맞혔지만 소수 클래스의 다양한 모습을 충분히 학습했는지는 확인되지 않음 | 삼각형·사각형 데이터를 보강하고 클래스별 재현율을 계속 확인. 필요하면 클래스 가중치나 샘플링 전략을 비교 |
| 입력이 단순 합성 도형이며 해상도가 32×32임 | 실제 사진, 복잡한 배경, 조명·위치·크기 변화에 대한 성능은 확인되지 않음 | 학습에 적절한 위치·크기·배경 변화를 추가하고, 새로운 조건의 독립 평가 데이터를 확보. 증강 시 도형의 라벨 의미가 유지되도록 조정 |
| 같은 검증 집합으로 epoch를 선택하고 성능도 보고함 | 모델 선택에 사용된 데이터에서의 성능으로, 독립적인 최종 평가 결과는 아님 | 실습의 test 미사용 규칙을 유지하고, 허용된 최종 평가 절차나 별도 독립 데이터에서 일반화 성능을 확인 |
| 전이학습의 효과를 분리한 비교 실험이 없음 | 높은 성능을 확인했지만 사전학습 자체가 얼마나 기여했는지는 수치로 분리할 수 없음 | 동일한 데이터·학습 조건에서 무작위 초기화 모델과 사전학습 모델을 비교 |
| Head만 학습하는 전략을 사용함 | 다른 종류의 데이터에서도 고정된 특징이 충분할지는 확인되지 않음 | 데이터가 충분해지면 마지막 합성곱 층을 작은 학습률로 함께 조정하는 후보와 비교. BatchNorm 정책과 과적합 여부도 확인 |

현재의 검증 정확도와 Macro F1은 이미 최댓값이므로, 같은 9장에서 정확도를 더 높이는 방식으로 개선을 판단할 수는 없다. 이후에는 평가 데이터의 수와 다양성을 늘려 성능이 유지되는지를 확인하는 것이 우선이다. 오답이 발생하면 실제 클래스·예측 클래스·softmax 값·이미지 특성을 함께 기록하여 원인을 분석할 수 있다.

재현성을 높이려면 난수 시드, 데이터 분할, 클래스 매핑, 전처리, 사전학습 가중치의 출처와 해시, 라이브러리 버전을 함께 기록해야 한다. 데이터 규모가 커질 경우에는 전체 이미지를 한 번에 메모리에 쌓는 현재 방식 대신 DataLoader와 미니배치를 도입할 수 있다. Grad-CAM을 분석 자료로 사용할 때는 이미지 저장 성공과 실제 파일을 확인하고, 열지도를 정답의 근거나 인과관계로 단정하지 않아야 한다.
