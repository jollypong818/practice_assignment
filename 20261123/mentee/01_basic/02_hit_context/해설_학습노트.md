# 실습 02 · Hit에서 Context 만들기 · 학습노트

**기본필수 / 수강생용 개념 설명**

## 이번 단계가 필요한 이유

이번 실습은 순수 Python의 dict·list·str를 연결합니다. 검색 순위를 새로 계산하지 않고 준비된 Hit의 순서를 사용합니다. 중복 제거·전체 블록 길이 제한은 실습 06에서 구현하므로 지금은 선택한 본문과 ID가 같은 출처를 가리키는지 집중합니다.

## 코드를 읽는 순서

### 1. format_hit

[ID] 원문위치, 줄바꿈, 본문 순서로 한 블록을 만듭니다.

생각할 점: citation_id·source_locator·body를 읽어 f-string으로 연결합니다. 입력이 실제로 어떤 값인지 먼저 출력해 보고, 함수의 반환값이 다음 단계에서 어디에 쓰이는지 연결해서 읽습니다.

### 2. make_context

앞의 최대 2건에서 블록과 ID를 함께 모아 반환합니다.

생각할 점: 선택한 Hit마다 format_hit을 호출하고, 블록은 빈 줄 두 개로 연결합니다. 입력이 실제로 어떤 값인지 먼저 출력해 보고, 함수의 반환값이 다음 단계에서 어디에 쓰이는지 연결해서 읽습니다.

## 결과를 해석하는 순서

1. outputs JSON의 execution과 입력 출처를 먼저 읽습니다.
2. 원문 본문·ID·위치가 출력의 어느 필드에 남았는지 찾습니다.
3. expected의 조건과 대조하고, 다르면 처음 어긋난 함수의 입력·출력부터 확인합니다.
4. reports/review.md에 “어떤 값이 근거인가?”를 자신의 말로 기록합니다.
