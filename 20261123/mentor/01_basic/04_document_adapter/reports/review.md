## 1. Document 생성 성공이 실제 검색 성공을 뜻하나요?

아닙니다. 기본 실행은 준비된 Hit를 변환한 결과입니다. 실제 검색 여부는 input_source와 execution으로 구분합니다.

## 2. citation_id를 항상 201로 넣으면 어떤 문제가 생기나요?

실제 DB에서 나온 다른 ID가 바뀌어 답변과 원문 연결이 깨집니다.

## 3. 빈 Hit 목록과 source_locator 누락은 왜 다르게 다루나요?

전자는 후보가 없는 정상 결과이고 후자는 출처 계약이 깨진 입력 오류입니다.
