## 1. 본문과 ID를 같은 반복문에서 모으는 이유는 무엇인가요?

모델에 제공한 근거와 허용 출처 목록이 같은 선택을 가리켜야 하기 때문입니다.

## 2. hits[:2]인데 한 건만 있는 경우 어떻게 되나요?

있는 한 건만 선택됩니다. 2건을 만들어 내지 않습니다.

## 3. len(context)는 Token 수인가요?

아닙니다. Python 문자열의 문자 수입니다. Token 수는 해당 모델의 Tokenizer로 계산해야 합니다.
