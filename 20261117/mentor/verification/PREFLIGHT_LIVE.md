# 강의 PC의 실제 사전검수

제작 환경의 모의 검사로 다음 항목을 대체하지 않습니다. 결과 칸은 강사가 실제 확인한 뒤 채웁니다.

| 검사 | 실행·확인 | 제작 환경 상태 |
|---|---|---|
| 설치 | openai·pydantic·dotenv 버전 기록 | SDK 설치 미검증 |
| 정상 응답 | 01 live --allow-paid, 실제 request/response ID | 실제 호출 미검증 |
| Structured Outputs | 02 live, 네 필드·출처·실제 근거 | 실제 호출 미검증 |
| Streaming | 03 live, delta·완료·사용량·시간 | 실제 호출 미검증 |
| 캐시 | 사람 검토 후 reuse, 새 전송 0회 | 모의 경로 확인, 실제 응답으로 재확인 필요 |
| 본문 변경 | changed, 다른 key와 별도 호출 | 모의 경로 확인, 실제 응답으로 재확인 필요 |
| 계정·단가 | 모델 접근권·잔액·승인 단가 | 사용자 계정 미접속 |
| Windows | VS Code·PowerShell·.env·경로·UTF-8 | 직접 조작 미검증 |

정상 실제 경로만 소수 호출합니다. 실패는 04의 모의 테스트로 확인하며, 실제 429를 만들려고 반복 호출하지 않습니다.
키나 개인정보를 검수 보고서에 붙이지 않습니다. SDK 설치 후 검증한 환경의 pip freeze를 보관하되 `.env`는 배포하지 않습니다.

명령은 `docs/SETUP.md`와 `docs/COMMANDS.md`에서 복사할 수 있습니다. API 키는 각자의 PC에만 설정합니다.
