## 실행
선택한 role 폴더(`mentor`)에서 다음을 실행합니다. 가상환경 Python을 사용하세요.
```powershell
python 01_basic/05_usage_cost/main.py --run-file "앞_교시_outputs/runs/실제_run_id/run.json"
```
코드분기먼저확인하려면같은명령의실제호출옵션대신 `--source simulated`를사용합니다. 05는이옵션에서공식계산용fixture만사용합니다. 04는항상모의입니다.

## 예상 결과와 완료 확인
모의공식예시는0.00138USD. 실제비용은usage와모델/단가가확인돼야계산됩니다.

실제모델응답문장은고정정답으로제공하지않습니다. `outputs/runs/<run_id>/run.json`과원문을함께봅니다. outputs폴더가없는초기상태가정상입니다. 코드실행전의예상값을실측으로표기하지마세요.

**주의:** 없는usage는None입니다. 이실습은run파일을읽고새로호출하지않습니다.
