## 실행
선택한 role 폴더(`mentor`)에서 다음을 실행합니다. 가상환경 Python을 사용하세요.
```powershell
python 01_basic/01_first_call/main.py --source live --allow-paid
```
코드분기먼저확인하려면같은명령의실제호출옵션대신 `--source simulated`를사용합니다. 05는이옵션에서공식계산용fixture만사용합니다. 04는항상모의입니다.
